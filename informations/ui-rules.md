# UI Rules – Couleurs, Tags, Icônes

## Catégories

- Chaque événement a UNE catégorie unique.
- La catégorie détermine la couleur de la carte dans le calendrier.

| Catégorie   | Couleur associée |
|-------------|------------------|
| SPECTACLE   | Bleu             |
| EXPOSITION  | Rouge            |
| REUNION     | Vert             |
| FESTIVAL    | Jaune            |
| AUTRE       | Violet           |

## Tags

- Jusqu’à 3 tags par événement
- Affichés sous forme d’icônes en bas à droite des cartes
- Aident à identifier rapidement le type d’événement

| Tag             | Icône              |
|------------------|--------------------|
| MUSIQUE         | 🎵 (note)          |
| DANSE           | 🩰 (danseuse)       |
| PLEIN AIR       | ☀️ (soleil)         |
| RENCONTRE       | 🤝 (main)           |
| FEU D’ARTIFICE  | 🎆 (feu)            |
| SPORT           | ⚽ (ballon)         |
| MARCHÉ          | 🏠 (maison)         |
| COURSE          | 🏁 (drapeau départ) |
